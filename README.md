# Badge

> **Created by Antono** | 🇮🇩 Indonesia

A web-based badge maker tool for creating custom badges, labels, and stickers.

## ✨ Features

- 🎨 Create custom badges
- 📝 Add text and images
- 📥 Export in multiple formats
- 📱 Responsive design

## 🚀 Getting Started

```bash
git clone https://github.com/antono4/badge.git
cd badge
open index.html
```

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
